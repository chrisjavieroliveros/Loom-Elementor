# Loom Elementor Widgets

A WordPress plugin that provides custom Elementor widgets for embedding Loom videos.

## Description

Loom Elementor Widgets adds a powerful and easy-to-use widget to Elementor for embedding Loom videos directly into your WordPress pages. This plugin seamlessly integrates Loom's video platform with Elementor's page builder.

## Features

- **Loom Video Widget**: Easily embed Loom videos using their share URLs
- **Customizable Settings**:
  - Multiple aspect ratio options (16:9, 4:3, 1:1, 9:16)
  - Autoplay option
  - Hide video owner option
  - Hide video title option
  - Responsive width controls
  - Alignment options (left, center, right)
- **Custom Widget Category**: All Loom widgets are organized under their own category in Elementor
- **Fully Responsive**: Videos adapt perfectly to any screen size

## Requirements

- WordPress 5.0 or higher
- PHP 7.0 or higher
- Elementor 3.0.0 or higher

## Installation

1. Upload the plugin files to the `/wp-content/plugins/loom-elementor-widgets` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Make sure Elementor is installed and activated.
4. Start using the Loom Video widget in Elementor!

## Usage

1. Edit a page with Elementor
2. Search for "Loom Video" in the widgets panel
3. Drag the widget to your desired location
4. Paste your Loom video share URL in the widget settings
5. Customize the appearance and behavior options
6. Publish or update your page

## Loom URL Format

The widget accepts Loom share URLs in the following format:
- `https://www.loom.com/share/VIDEO_ID`
- `https://loom.com/share/VIDEO_ID`
