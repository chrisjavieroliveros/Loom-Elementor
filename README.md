# Loom Elementor Widgets

A WordPress plugin that provides custom Elementor widgets for embedding Loom videos and other features.

## Description

Loom Elementor Widgets extends Elementor page builder with custom widgets designed to seamlessly integrate Loom video content into your WordPress site. This plugin makes it easy to embed Loom screen recordings, video messages, and tutorials directly into your Elementor-designed pages.

## Features

- **Loom Video Widget**: Easily embed Loom videos using URL or video ID
- **Responsive Design**: Videos automatically adjust to different screen sizes
- **Customizable Aspect Ratios**: Choose from 16:9, 4:3, 1:1, or 21:9
- **Alignment Options**: Left, center, or right alignment
- **Width Control**: Adjust video width with percentage or pixel values
- **User-Friendly Interface**: Intuitive controls integrated into Elementor editor

## Requirements

- WordPress 5.0 or higher
- PHP 7.0 or higher
- Elementor 3.0.0 or higher

## Installation

1. Upload the plugin files to the `/wp-content/plugins/loom-elementor-widgets` directory, or install the plugin through the WordPress plugins screen directly
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Make sure Elementor is installed and activated
4. Find the new "Loom Widgets" category in the Elementor editor

## Usage

### Loom Video Widget

1. Edit a page with Elementor
2. Search for "Loom Video" in the widgets panel or find it under "Loom Widgets" category
3. Drag the widget to your desired location
4. In the widget settings, enter your Loom video URL (e.g., `https://www.loom.com/share/abc123`)
   - Alternatively, you can enter just the video ID
5. Customize the appearance using the Style tab:
   - Adjust width
   - Select aspect ratio
   - Set alignment
6. Update/publish your page

## Widget Settings

### Content Tab
- **Loom Video URL**: Enter the full Loom video URL
- **Loom Video ID**: Alternatively, enter just the video ID

### Style Tab
- **Width**: Control the video container width (responsive)
- **Aspect Ratio**: Choose from 16:9, 4:3, 1:1, or 21:9
- **Alignment**: Left, center, or right alignment

## Supported Loom URL Formats

The widget supports the following Loom URL formats:
- `https://www.loom.com/share/VIDEO_ID`
- `https://loom.com/share/VIDEO_ID`
- `https://www.loom.com/embed/VIDEO_ID`
